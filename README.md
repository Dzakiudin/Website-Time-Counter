# ⏳ Website Time Counter (Chrome Extension)

Website Time Counter adalah ekstensi Chrome *open-source* sederhana yang membantu Anda melacak total waktu yang dihabiskan di setiap situs web setiap hari. Ini adalah alat yang hebat untuk memahami dan mengelola kebiasaan digital Anda.

## 📜 Tentang Proyek

Proyek ini dibuat untuk menyediakan cara yang ringan dan *privacy-first* untuk memantau produktivitas atau kebiasaan *browsing*. Semua data disimpan secara lokal di *browser* Anda dan direset secara otomatis setiap hari.

## ✨ Fitur

  * **Pelacakan Waktu Otomatis**: Secara otomatis menghitung waktu (dalam jam, menit, dan detik) yang Anda habiskan di tab yang sedang aktif.
  * **Laporan Harian**: Menampilkan ringkasan semua situs yang Anda kunjungi hari ini, diurutkan berdasarkan waktu terlama.
  * **Deteksi *Idle***: Secara cerdas berhenti menghitung waktu jika Anda tidak aktif (tidak ada gerakan mouse atau input keyboard) untuk sementara waktu.
  * **Fokus Privasi**: Semua data pelacakan disimpan di penyimpanan lokal *browser* Anda. Tidak ada data yang dikirim ke server eksternal.
  * **Reset Harian**: Timer secara otomatis direset setiap hari, memberi Anda ringkasan yang bersih untuk hari yang baru.
  * **Reset Manual**: Opsi untuk menghapus semua data pelacakan hari ini secara manual kapan saja.

## 🚀 Instalasi

### 1\. Instalasi Manual (Untuk Developer / Pengguna)

Anda dapat menginstal ekstensi ini secara manual dari *source code*:

1.  *Download* atau *clone* repositori ini:
    ```bash
    git clone https://github.com/[NAMA_USER_ANDA]/[NAMA_REPOSITORI_ANDA].git
    ```
2.  Buka Google Chrome dan navigasikan ke `chrome://extensions`.
3.  Aktifkan **"Developer mode"** di pojok kanan atas.
4.  Klik tombol **"Load unpacked"**.
5.  Pilih folder tempat Anda men-*download* atau men-*clone* repositori ini.

Ekstensi sekarang akan aktif dan ikonnya akan muncul di *toolbar* Chrome Anda.
